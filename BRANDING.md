## Visual Identity

### Design Principles
1. **Dark-first**: The app is designed for dark mode as default
2. **Glassmorphism**: Cards use frosted glass effect (backdrop-filter: blur)
3. **Energetic**: Coral accents, pulse animations, heart-rate beats
4. **Premium**: Smooth transitions, rounded corners (24px), subtle shadows
5. **Minimal**: Clean layouts, plenty of negative space, focused UI

### UI Elements
- **Cards**: Glass-effect with `rgba(255, 255, 255, 0.04)` background
- **Buttons**: Pill-shaped (border-radius: 100px), gradient accents
- **Timer**: Circular SVG progress ring with gradient stroke
- **Navigation**: Bottom tab bar with active indicator
- **Notifications**: Slide-in cards with waveform animation

### Motion Guidelines
- **Timer pulse**: 2s infinite heartbeat animation on active state
- **Button transitions**: 0.2s ease for hover/active states
- **Page transitions**: 0.3s ease-out for navigation
- **Loading**: 1.5s ring spin with arc rotation
